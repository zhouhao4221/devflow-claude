# 插件架构

## 概述

插件架构模块负责 DevFlow 工具集自身的**分发与维护机制**——即 5 个插件（req/api/pm/diag/uat）的命令、技能、脚本、钩子如何组织、生成与保持一致，而非任一插件的业务功能。

模块核心关注点：

- **双形态分发**：每个能力同时以 `commands/<name>.md`（标准 Claude Code）与 `skills/<name>/SKILL.md`（不支持 slash 的客户端）两种形态提供，二者须功能等价。
- **单一权威源**：command 为 source of truth，skill 由确定性脚本派生，杜绝两份漂移。
- **维护心智模型**：命令/技能是「给 Claude 的指令文档」，脚本只做确定性副作用。

## 关键文件

- `plugins/<plugin>/commands/*.md` — 命令权威源（含 `_*.md` 共享子文件）
- `plugins/<plugin>/skills/<name>/SKILL.md` — 派生技能镜像 + 手写 helper skill
- `scripts/gen-skills.py` — 派生脚本（规划中）
- `CLAUDE.md` — 「命令与技能结构」维护规范
