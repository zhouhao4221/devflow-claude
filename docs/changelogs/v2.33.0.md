# v2.33.0

**发布日期**: 2026-05-12

## 新特性 (Features)

### UAT 插件增强

- **代码分析生成指导文件**: `/uat:new` 代码分析模式合并到主流程
  - 自动扫描前端路由、表单组件、OpenAPI 接口定义
  - 推导 CRUD 场景建议并自动标注代码来源
  - 用户确认后一键生成 flow 文档

- **Console 错误捕获**: 测试执行时自动监听 console.error
  - 捕获为 ⚠️ PASS 警告（功能通过但有异常）
  - 补充到测试报告「Console Errors」节

- **截图附件自动上传**: Bug 上报工单时自动附加失败截图
  - GitHub: 通过 upload API 自动关联到 issue
  - Gitea: 通过 assets API 自动上传附件
  - 无需手动附件操作

### 执行引导优化

- **意图驱动执行**: 步骤写自然语言，执行器自选工具和定位方式
  - testid / aria-label 降为**可选提示**，不强制
  - 支持视觉截图兜底（找不到元素时截图 → Claude 分析）
  - 元素定位优先级：testid > 语义角色 > 无障碍属性 > 上下文位置 > 视觉分析

- **下拉选择高效操作**（新增）
  - **字段定位优先**: 先找字段触发器，不从选项文本开局（避免同名歧义）
  - **浮层范围限定**: 打开下拉后只看新出现浮层，同名选项用活跃浮层消歧
  - **键盘筛选优先**: 下拉打开后直接输入选项名过滤，比列表翻找快
  - **页面记忆**: 字段顺序确认一次后直接复用，不每次重新探索
  - **避免 Esc 关闭**: 改用点击外侧或下一个字段，避免意外关闭弹窗

## 重构 (Refactor)

- **代码分析独立命令移除**: `/uat:analyze` 合并到 `/uat:new`，命令数减少，流程更简洁

- **执行中流程文档更新**: 简化逻辑，移除过度设计的发现项机制
  - 发现步骤描述有误时直接更新 `docs/uat/flows/<module>.md`
  - 无需中断执行或额外交互

- **意图驱动执行**: 步骤写自然语言，执行器自选工具和定位方式
  - 移除选择器前置要求（testid 可选）
  - 支持跨浏览器框架定位（ant-design / element / 自定义组件）

## 文档 (Docs)

- **高效 UAT 操作技巧**: 补充下拉选择、级联选择、浮层交互的最佳实践
  - 字段定位、键盘筛选、页面记忆等 7 个核心技巧

- **需求文档更新**: REQ-002（UAT 插件）补充变更记录和最终实现方案

## 关键改进总结

| 方向 | 变化 |
|------|------|
| 执行策略 | 意图驱动 + 工具自选（不依赖选择器前置） |
| 元素定位 | testid 可选提示 → 支持多种定位方式 + 视觉兜底 |
| 下拉操作 | 字段优先 → 键盘筛选 → 浮层限定范围 → 页面记忆 |
| 错误追踪 | console.error 自动捕获 → ⚠️ PASS 警告 |
| 数据追踪 | 失败截图自动上传到 issue，无需手动附件 |
| 命令精简 | `/uat:analyze` 合并到 `/uat:new`，删除独立命令 |
