# v2.38.0 (2026-08-24)

## 功能

### 新增

- **feat(req): 命令内 subagent 委派机制**
  - 新增 `plugins/req/agents/`：`test-runner`（haiku）跑测试只回失败摘要、`code-scout`（haiku）代码定位只回 file:line 清单、`file-reviewer`（sonnet-5）单文件 diff 审查
  - 新增 `commands/_delegate.md` 委派规范；接入 `test` / `test_new` / `dev` / `fix` / `do` / `review-pr`（review-pr 仅 >10 文件或 >800 行才 fan-out）
  - 原始输出（测试日志、大 diff、全库搜索）留在 subagent，不进入主会话上下文
- **feat(pm): 生成类命令降级 claude-sonnet-5**
  - `weekly` / `monthly` / `milestone` / `stats` / `progress` / `brief` / `risk` 显式 `model: claude-sonnet-5`
  - `plan` / `ask` 需要真实推理，保持继承会话模型

### 改进

- **共享 `_*.md` 去互引，skill 体积 -46%**
  - 头部「同伴文档」链接改纯文本，切断 gen-skills 传递闭包内联
  - skill 总体积 946KB → 515KB，超 30KB 的由 20 个降至 2 个
- **模型分级改三档**（haiku / `claude-sonnet-5` / 省略）
  - 已核实 Sonnet 5 原生 1M 上下文、超 200K 不加价、订阅不计 extra usage；移除旧「sonnet 付费墙」注记
- `fix` / `do` 改码完成后自动派 `test-runner` 回归变更相关测试
