# v5.1.1 (2026-09-23)

> 版本范围：v5.1.0..HEAD（#98 #99 #100）

## 改进

- **命令不再指定模型，统一跑会话模型**（#100）
  - 背景：实测命令 frontmatter 的 `model` 从未生效——Claude Code 2.1.239–2.1.280 约 200 次声明 haiku / sonnet 的命令调用，全部跑在会话模型上
    - Haiku：auto 模式（Pro / Max / Team 默认）不支持 Haiku，官方文档写明会被忽略、会话保持当前模型
    - Sonnet：受 anthropics/claude-code#81318 影响（v2.1.220 起命令 / skill 的 `model` / `effort` 覆盖静默失效）
    - 即便生效，同一对话里换模型要按新模型重写整段历史的 prompt cache，小命令多半更贵
  - 48 条命令删除 `model`（rd / pm / api / diag，原 haiku 33 条、sonnet 15 条）；想省钱用 `/model` 切换整个会话
- **子代理按特性设置 effort**（#100）

  | 子代理 | model | effort |
  |--------|-------|--------|
  | test-runner · diff-digest · doc-writer | 会话模型（`inherit`） | medium |
  | code-scout · impl-worker | 会话模型（`inherit`） | high |
  | planner · root-cause | fable | xhigh |

  - 原 haiku（4 个）/ sonnet（impl-worker）执行型子代理改为跟随会话模型：Haiku 4.5 不支持 effort、上下文只有 200K；Sonnet 5 缓存读价与 Opus 5.5 相同，省得有限
  - effort 下限 medium：子代理结论被主会话直接采信，漏报 / 错报的代价高于省下的 thinking
