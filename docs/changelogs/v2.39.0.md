# v2.39.0 (2026-08-24)

## 修复

- **fix(plugins): 斜杠菜单里每条命令不再重复出现**（QUICK-002）
  - 删除 51 个命令镜像 skill（req 23 · pm 12 · api 6 · uat 6 · diag 4）。Claude Code 2.x 把插件 skill 也暴露成 `/<plugin>:<skill>`，与同名 command 落在同一个菜单里、`description` 逐字相同，两项无法区分
  - 12 个共享参考文档（`_storage.md`、`_common.md`、`release-rationale.md` 等）移出 `commands/` 到 `plugins/<p>/shared/`——`commands/` 下每个 `.md` 都会被注册，它们此前变出了 `/req:_storage` 这类伪命令
  - 菜单项 142 → 78（req 77→44 · pm 27→14 · api 16→8 · uat 13→7 · diag 9→5），对应的 always-on description 开销一并省下
- **fix(req): 移除 `scripts/migrate-config.sh` 幽灵引用**
  - 该脚本在仓库中从不存在，却被 `migrate.md`、`_storage.md`、CLAUDE.md 三处引用；迁移逻辑本就写在 `/req:migrate` 命令自身，三处改为指向该命令

## 改进

- **`gen-skills.py` 派生器退役，换成 `scripts/check-layout.py` 布局守卫**
  - 一次守住三条：`skills/` 无命令镜像 · `commands/` 只放真命令（需 frontmatter + `description`）· 所有 Markdown 相对链接可达
  - `--check` 报错退 1（已接入 `/req:release` 发布前置），无参运行自动清理镜像与散落文件
- **api / pm 命令对 `_common.md` 的引用补上路径**
  - 原先 5 个文件只写纯文本 `` `_common.md` ``、不给路径，首处提及升级为 `../shared/_common.md` 链接
- **`version-bumper` 补齐 uat 插件**
  - 版本文件表与路径归属表此前漏了 `plugins/uat/`，uat 的版本号不会被自动 bump

## 破坏性变更

- `skills/<命令名>/SKILL.md` 形态的入口全部移除。**Claude Code 用户不受影响**——所有能力经 `/<plugin>:<command>` 照常调用，且菜单不再重复。仅依赖 skill 形态、不支持 slash 的客户端会失去这 51 个入口
- 引用 `plugins/<p>/commands/_*.md` 或 `commands/release-rationale.md` 路径的外部脚本需改为 `plugins/<p>/shared/`
