# v2.40.1 (2026-08-26)

> 版本范围：v2.40.0..HEAD

## 修复

- **fix(req): 修 4 个 agent 定义的实测缺陷，补运行时生效链路规则**
  - v2.40.0 发布后用受控沙箱实测三个新 agent（沙箱里埋了一个「越界陷阱」：某个测试只有改动实施单之外的文件才能通过）。`impl-worker` 通过陷阱——未修改越界文件、如实上报「越界需求」、状态标 PARTIAL 而非谎报 DONE，自验结果与独立复跑逐条一致，本次无需调整。另两个各暴露一类缺陷
  - **`doc-writer` 自造分类标签**：素材第一节只列了新增的三个 agent 未给类型（类型信息在第三节素材里），它自行补了「可写型」标签并把只读的 `diff-digest` 归了进去，导致同一份文档第一节与第三节自相矛盾。原规则「不发明事实」拦不住这类补全，且只说了不要做什么
    - 拆出规则 3「限定语照抄素材」：类型/归属/状态/优先级只能来自素材原文，素材归了类就照抄，没归类就只写它是什么
    - 拆出规则 4「落盘前通读全文查矛盾」：素材各章详略不同是常态，详略不等于让你去补齐；以最明确的那处为准，改齐再落盘
    - 返回格式新增「跨章节一致性」和「素材外的推断」两行，让规则可核对而非停留在口号
  - **`diff-digest` 每文件行数靠目测**：12 个文件报错 7 个（`CLAUDE.md` 报 +95/-25，真实 +30/-16；两个 JSON 报 +0/-0，真实各 +1/-1），总量因取自 `--shortstat` 反而接近正确。根因是规则只要求「给出 +/- 行数」却没说怎么拿
    - 规则 4 明确：行数必须用 `git diff --numstat` 一次取全表逐行照抄，绝不目测、绝不从 hunk 里数
  - **`diff-digest` 逐轮落盘耗尽轮次**：16 个文件一个一轮地写，15 轮只完成 11 个，最后一轮吐出过渡句就结束
    - 规则 3 明确必须用一条循环命令批量落盘；`maxTurns` 15 → 20；落盘行加「已写入 n/总数」
    - 该次超轮按 v2.40.0 新增的「超轮与失败处理」用 SendMessage 续问恢复成功，恢复路径本身验证通过
  - **轮次纪律条款补齐**：此前只加进了 `impl-worker` 和 `file-reviewer`，`diff-digest`、`code-scout`、`test-runner` 三个漏了，现 6 个 agent 全覆盖

## 文档

- CLAUDE.md 新增维护规则 #10：**本仓库工作区的改动对 Claude Code 运行时无效**。运行时加载 `~/.claude/plugins/cache/devflow/<plugin>/<version>/`，`/plugin` 更新从 `~/.claude/plugins/marketplaces/devflow`（GitHub 克隆）拉取，cache 按版本号分目录——不 bump 版本号时 `/plugin` 会报 `already at the latest version` 而不更新。要让改动生效并可实测，必须走完：提交 → push → `/plugin` 更新 → `/reload-plugins`；在此之前跑 subagent 测的都是旧定义
