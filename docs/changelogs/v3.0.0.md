# v3.0.0 (2026-09-15)

> 版本范围：v2.42.1..HEAD（#70 #71 #72 #73）

## 修复

- **fix(req): 命令正文残留的 v2 配置路径与缓存同步逻辑全部对齐 v3**（#73）
  - `/req:branch init` 把 `branchStrategy` / `giteaToken` 写进 `.claude/settings(.local).json`，而 commit / pr / issue 按规范去 `.devflow/` 读，配完读不到——改为写 `.devflow/`；status / show / prd / req / projects / release / commit / pr / issue / update-template 与 `issue-guide` 的读取位置同步修正，`giteaToken` 明确为 `.devflow/settings.local.json` 顶层字段
  - 按已移除的缓存执行的步骤全部删除：new-quick / upgrade 编号扫缓存并复制到 `$CACHE_ACTIVE`；review / edit / prd-edit / done / specs 的「同步缓存」步骤与并不存在的「PostToolUse Hook 自动同步」说法；status / show / changelog / commit / dev-guide 的「回退读缓存」
  - `/req:projects` 原基于已废弃的全局中心索引，按 v3 语义重写为展示当前仓库对应的需求项目
  - 未定义的 `<plugin-path>` 占位符（req 14 · pm 2 · api 3）改为 `${CLAUDE_PLUGIN_ROOT}`；`update-template` 不再靠 `extraKnownMarketplaces` 猜插件目录
- **fix(pm): 需求目录解析改读 `.devflow`**（#70）
  - 原先 primary 写死 `docs/requirements`、注释指向 `.claude/settings.local.json`、primary 分支残留 v2 缓存逻辑——改过 `requirementsDir` 的项目报表为空
- **fix(pm): 报告命令保存不再每次弹确认**（#72）
  - weekly / monthly / milestone / progress / risk / brief 生成后写 `docs/reports/`，`allowed-tools` 补 `Write` 与 `mkdir` 预授权
- **fix(api): `_common.md` 脚本调用示例与实际参数不符**（#70）
  - `--search` 参数不存在（argparse 直接报错）、`--path` 不带 `--mode detail` 会静默返回 summary；改为 mode 参数表，脚本路径用 `${CLAUDE_PLUGIN_ROOT}`
- **fix(diag): Hook 完整性校验「会话内只校验一次」从未生效**（#70）
  - marker 名含 `$$`，每个 Hook 进程都不同——启用 diag 后任何项目的每条 Bash 都跑一遍校验并在 `/tmp` 留文件；改为仅含 ssh 的命令校验，marker 按 `session_id` 落 `$DIAG_HOME/runtime/` 并清理旧 marker；冒烟测试补 2 例，37/37 通过

## 改进

- **`check-layout.py` 新增过时引用检查 + GitHub Actions CI**（#73）
  - 插件内出现 `.claude/settings*` 读写 DevFlow 字段、`sync-cache` / 全局缓存、缓存同步类表述、`<plugin-path>` 即报错；迁移说明与 Claude Code 自身配置项豁免，行尾 `stale-ok` 可显式豁免。同类残留已两次造成静默失效（v2.39.1 的 hook、本次的 req 命令）
  - `.github/workflows/check.yml`：每个 PR 与 main push 自动跑布局守卫和 diag 冒烟测试
- **子任务委派扩到 api / diag**（#70）
  - `/api:gen` 引用文件 > 5 个或 `--tag` 批量时、`/diag:diagnose` 堆栈帧涉及 > 5 个文件时，派内置 `Explore` 定位；diag 拉日志的 SSH 始终留在主会话保证审计完整
- **精简与清理**（#70 #73）
  - pm `_common.md` 删 Python 伪代码改为口径说明，8.6KB → 4.0KB
  - 删除 5 个无调用方的死脚本：pm `collect-git-stats.sh`；req `update-status.sh`（调用已删除的 `sync-cache.sh`）、`check-conflict.sh`、`check-requirement-link.sh`、`parse-requirement.sh`

## 破坏性变更

- **移除 uat 插件**（#71）：CLI 里驱动浏览器逐场景做 UI 验收不合适。已安装 `uat@devflow` 的用户更新 marketplace 后该插件不再可用，需手动卸载；项目内 `/uat:init` 复制的 `.claude/skills/uat-executor/` 与 `docs/uat/` 需自行清理
- **help 语言偏好位置变更**：`language` 字段从 `.claude/settings.local.json` 改读 `.devflow/settings.local.json`（req / pm / api），已设置的需搬过去
- **`/req:projects` 输出语义变更**：不再列「所有项目」（v3 本就无全局索引），只展示当前仓库对应的需求项目
