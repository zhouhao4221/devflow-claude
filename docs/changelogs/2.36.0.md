## ✨ 新增

### 全插件迁移
- **将所有 command 迁移为 skill**（飞书 Claude AI 兼容性）
  - 5 个插件（api/pm/diag/req/uat）中的 66 个 command 转换为对应的 skill 文件
  - 保持原有功能不变，使其可在不支持 slash command 的飞书 Claude AI 中通过 skill 调用
  - api: 7 个 skill · pm: 13 个 skill · diag: 4 个 skill · req: 36 个 skill · uat: 6 个 skill

### req 插件
- **readonly 仓库支持模板文件初始化**
  - readonly 仓库在初始化时可以使用项目模板文件，简化只读模式的项目初始化流程
