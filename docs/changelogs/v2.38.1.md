# v2.38.1 (2026-08-24)

> 版本范围：v2.38.0..HEAD

## 修复

- **fix(req): 插件 manifest 移除非法 `agents` 字段，修复 req 插件安装失败**
  - v2.38.0 随 subagent 委派机制在 `plugins/req/.claude-plugin/plugin.json` 写入 `"agents": "./agents/"`，而 manifest schema 中 `agents` 只接受 **agent 文件路径数组**（不接受目录字符串），导致 `/plugin` 安装报 `Validation errors: agents: Invalid input`，req 4.1.0 全程装不上
  - 直接删除该字段：schema 定义为「设置时 `agents/` 目录不再自动加载」，即省略时 `agents/` 本就自动发现，三个 subagent 照常生效且新增 agent 无需改 manifest
  - 校验通过：`claude plugin validate .`（marketplace）、`plugins/req`（manifest）、`plugins/req/agents`（3 个 agent 定义）
