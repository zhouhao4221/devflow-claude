# v5.3.2 (2026-09-29)

> 版本范围：v5.3.1..HEAD（#107）

## 问题修复

- **hook 路径含空格时失效**：rd、diag 的 `hooks.json` 中 `${CLAUDE_PLUGIN_ROOT}` 加 shell 引号。之前 home 路径含空格（Windows / macOS 常见用户名）时 hook 命令被拆词、静默不执行（`claude plugin validate` 警告）
- **只有 `AGENTS.md` 的项目被架空**：Claude Code 2.1.277 起，项目无 `CLAUDE.md` 时改读 `AGENTS.md`。`/rd:init` 追加指针行、`/rd:use` 追加架构片段原来会新建 `CLAUDE.md`，导致 `AGENTS.md` 不再被读取；现在这类项目改为作用于 `AGENTS.md`，不再新建 `CLAUDE.md`
- **`/rd:use` 误报缺少架构描述**：架构检查原来只在 CLAUDE.md 里找关键词，而 `/rd:init` 把架构写进 `docs/prompt/architecture.md`、CLAUDE.md 只留指针；现在 `architecture.md` 存在即通过
- **`/rd:test_regression` 测试配置来源**：与 `/rd:test` 对齐为 `docs/prompt/testing.md` → `docs/prompt/architecture.md`「测试规范」→ CLAUDE.md（旧项目），不再只读 CLAUDE.md

## 其他

- 维护文档按 `/doctor prompt-audit` 清理过时说明（节名、计数、历史叙述）；发布前检查加本地 `claude plugin validate`
