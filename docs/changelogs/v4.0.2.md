> 版本范围：v4.0.1..HEAD（#79 #80 #81 #82）

## 修复

- **fix(QUICK-006): `/rd:pr merge` 补 gh 不可用时的处理，mergeMethod 改 squash**（#82）
  - 此前 merge 只写了 `gh pr merge`，gh 未登录时没有处理规则；status / review / comments 同样默认 gh 可用
  - 「gh 可用」统一为已安装且 `gh auth status` 通过，创建 PR 同步采用；只装未登录算不可用
  - gh 不可用时：只读查询回退公开 REST API，私有仓库无凭据时提示登录；提交审查评论、Approve、合并不执行，改为输出 PR 链接与手动操作指引
  - 合并按 `mergeMethod` 提示网页上对应的按钮（如 Squash and merge），用户回复已合后经 API 核实 `merged` 才提示 `/rd:done`

## 移除

- **chore: 移除 req 过渡插件**（#79）
  - marketplace 不再提供 `req`（原仅含 `/req:help` 迁移说明）；原计划保留到 v5，提前移除
  - 尚未改装的用户：更新 marketplace 后旧 `/req:*` 命令会消失，按 README / 教程 1.6 三步改装 `rd@devflow`（卸载 req、安装 rd、执行 `/rd:migrate`）
  - `check-layout.py`、`version-bumper`、CLAUDE.md、教程中英韩与 `migrate.md` 同步去掉过渡插件相关表述
