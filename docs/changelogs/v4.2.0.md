# v4.2.0 (2026-09-17)

> 版本范围：v4.1.2..HEAD（#91）

## 新功能

- **feat(rd): pr review 按文件分类调整路由与档位，纯样式/非代码 PR 不再起 /code-review**（#91）
  - 背景：前端纯样式 PR 因「缺测试」信号被系统性推到 high；批量改名、lock 更新这类 PR 只要超过 10 个文件就会被送去原生 `/code-review` 跑六分钟，而它的 fork 跑在会话模型上
  - 第 1 节改用 `git diff --numstat`，新增文件分类表（非代码 / 展示层 / 逻辑代码，只看路径后缀，不读内容）
  - 路由加一行「小 PR（非逻辑为主）」：非逻辑改动行 ≥ 80% 且逻辑代码部分 ≤ 10 文件且 ≤ 800 行时主会话内联审，只读逻辑代码 diff，非逻辑文件抽读改动最大的 3 个
  - 4.1「缺测试」分母只算逻辑代码文件；「非代码为主」改为「非逻辑为主」，非代码与展示层合并计算；输出行加 `文件分类：逻辑 n / 展示 n / 非代码 n`
  - 行为变化：纯样式、纯文案、批量改名、lock 更新类 PR 不再起 `/code-review`，档位下调一级；含逻辑代码的混合 PR 不受影响
