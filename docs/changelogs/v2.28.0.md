# v2.28.0

**发布日期**：$(date +%Y-%m-%d)

## 功能增强

### 需求管理（req）
- **初始化流程优化**：`/req:init` 现在在 `docs/prompt/` 预置 6 个通用 Prompt 骨架（code-generation / refactoring / test-generation / error-diagnosis / pr-review / requirement-structuring）+ `prompt-craft.md` 格式说明文件，统一 5 节结构（什么时候用 / 必备输入 / 触发方式 / 优质输出标准 / 常见失败模式）
- **重新初始化支持**：`--reinit` 模式现在完整检查 `docs/prompt/` 文档骨架，缺失时补创建

### 生产诊断（diag）
- **Runbook 预置**：`/diag:init` 新增步骤在 `docs/runbooks/` 创建 4 个事故处理骨架（db-slow-query / oom / 5xx-spike / deployment-rollback），诊断完事故后 AI 协作补写内容

### API 对接（api）
- **API 惯例文档**：`/api:config init` 新增步骤在 `docs/api/` 创建 3 个文档骨架（field-conventions / error-codes / auth-pattern），`/api:gen` 生成代码时自动读取保持一致性

## 技术细节

- 所有新建骨架文件采用统一 5 节结构，对齐 [prompt-craft 规范](https://zhouhao4221.gitbook.io/haiqing-docs/04-prompt/prompt-craft)
- 骨架文件节内容留空，由用户与 AI 协作填写，避免预置空白模板
